# Our Love Story · 情侣纪念日网页

纯静态（HTML / CSS / JS）的纪念页，无构建、无后端，可直接部署到 GitHub Pages、Netlify、Vercel、Cloudflare Pages 等静态托管平台。

视觉方向：**嫩粉底色 + 白色玻璃卡片 + 大字号编辑感排版**，用柔和渐变、留白和细线代替传统婚庆模板的爱心边框。

## ✨ 当前包含

- **纪念日倒计时**：自动计算在一起的天数，倒数到下一个纪念日（支持自定义固定日期）
- **故事卡片**：每条回忆一张玻璃质感卡片，最后一张用珊瑚渐变强调
- **里程碑追踪**：自动计算 100 天、6 个月、1 年、1000 天等节点，标记已达成与剩余天数，并显示下一个里程碑的进度条
- **一键复制**：把爱情数据排版成带分隔线与表情的纯文本，复制到剪贴板后可直接粘贴到聊天窗口
- **纪念卡片下载**：在浏览器里实时绘制 1080 × 1350 的 PNG 贺卡，适合发到社交平台，内容与页面数据保持一致
- **引言带**：一句写给彼此的话，作为首屏与故事之间的呼吸
- **轻量交互**：阅读进度条、数字缓动递增、光标跟随光晕、滚动渐显
- **加载优化**：不依赖外部字体与图片，全站仅 CSS/JS 两个静态资源，首屏无阻塞请求
- **适配**：桌面双栏 / 移动单栏，完整适配手机；支持 `prefers-reduced-motion`

> 留言区已移除；相册暂时隐藏但代码与数据保留，随时可以恢复。
>
> 复制、里程碑计算与卡片生成全部在浏览器本地完成，不会上传任何数据。

## 🛠 修改内容

只需要编辑 `js/data.js`：

| 位置 | 作用 |
| --- | --- |
| `couple` | 名字、恋爱起始日期、左上角站名 |
| `hero` | 首屏眉题、装饰文案、介绍、引言、天数/倒计时标签、固定纪念日 |
| `timeline` | 时间轴标题、描述、结尾语，以及每条回忆的 `date / title / desc / tag` |
| `milestones` | 里程碑节点与分享按钮文案 |
| `album` | 相册数据（暂时隐藏中，保留备用） |
| `footer` | 页脚落款与私人化文案 |

### 自定义里程碑

`milestones.items` 支持三种类型，按起始日期自动计算：

```js
{ label: "100 天", type: "days", value: 100 }
{ label: "6 个月", type: "months", value: 6 }
{ label: "1 年", type: "years", value: 1 }
```

- `days`：从起始日期往后数 N 天
- `months` / `years`：按日历月 / 年推进，遇到月末会自动取当月最后一天
- 节点会按日期自动排序，已达成的高亮并显示「已达成」，未达成的显示剩余天数，最近的那个标为「下一个」
- 复制文案与下载卡片都会同步读取这些数据

页脚文字默认是私人化落款（`小余 & 小周 · 2021 — ∞`），可自行替换成你们的。

## 📷 重新启用相册

1. `index.html` 中相册 `<section ... id="album" hidden>` 删除 `hidden`
2. 恢复导航里被注释的「相册」链接
3. 灯箱代码已保留，无需改动

## 🚀 部署到 GitHub Pages

1. 上传整个目录到 GitHub 仓库
2. **Settings → Pages** → Source 选 `Deploy from a branch`
3. 分支 `main`、目录 `/ (root)`，保存

访问 `https://<用户名>.github.io/<仓库名>/` 即可。
